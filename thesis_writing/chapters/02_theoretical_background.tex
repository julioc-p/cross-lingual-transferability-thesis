\section{Theoretical Background}\label{section::theoretical_background}

\subsection{Machine Learning}
\textit{Note that this section is based on the book ``Deep learning'' by Goodfellow et al. \cite{goodfellow2016deep} unless stated otherwise.}

\begin{definition}
A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E.
\end{definition}
The subsequent sections will explain these components (Task, Experience, Performance Measure) and other foundational concepts that underpin machine learning systems, contextualizing them broadly within the scope of this thesis. Although the techniques are abundant, they all mostly draw their foundations from the fields of optimization and probabilistic inference.

\subsubsection{Task, T}
The task refers to the specific problem the machine learning system is designed to solve.
Machine learning tasks are typically described in terms of how the system should process an \textit{example}, which is a collection of \textit{features} from an object or event. 
An example is usually represented as a vector $x \in \mathbb{R}^n$ with each component $x_i$ representing a feature.
Some of the most common classes of tasks include:
\begin{itemize}
    \item \textbf{Classification:} Assigning an input to one of a set of predefined categories. For example, determining if an email is spam or not spam.
    \item \textbf{Regression:} Predicting a continuous numerical value. For instance, forecasting the price of a stock.
    \item \textbf{Clustering:} Grouping similar data points together without predefined labels. An example is segmenting customers based on purchasing behavior.
    \item \textbf{Dimensionality Reduction:} Reducing the number of features while preserving important information. This can be used for data visualization or to simplify subsequent processing.
    \item \textbf{Summarization:} Creating a concise summary of a larger body of text or data.
    \item \textbf{Translation:} Converting text from one language to another.
    \item \textbf{Structured output:} Output is a data structure with multiple values that matain relationships between them.
\end{itemize}
For the purpose of this work, the term "prediction" and the verb "predict" will often be used in a general sense to encompass the output generation aspect of these various tasks.
In the context of this thesis, the primary task (T) falls under structured output generation, where the goal is to translate natural language questions into formal SPARQL queries. 
This task shares conceptual similarities with machine translation, involving the conversion from one linguistic representation (natural language) to another (a formal query language).

\subsubsection{Experience, E}
Experience refers to the data from which the system learns. A crucial assumption in most machine learning experiments is that past data, or a subset of it (referred to as training data), contains patterns that can generalize to new, unseen data. 
More formally, it is assumed that the training data and any future data the model encounters are sampled from the same underlying probability distribution. Other assumptions might be made depending on the specific problem and model, such as the independence of features or the existence of linear relationships between variables.
The experience (E) in this research is embodied by a large-scale, multilingual dataset composed of natural language question-SPARQL query pairs. This data, sourced from various knowledge extraction challenges, enables the models to learn the patterns required for the translation task. 
The study also explores the impact of different types of prior experience, such as that gained through continual pre-training of language models, which will be explained further down this chapter.

\subsubsection{Performance Measure, P}
The performance measure quantifies how well the model is performing the task T, based on the experience E. This is critical for both guiding the learning process and for evaluating the final model. 

The ones used in this work are:

\begin{itemize}
    \item \textbf{Cross-entropy loss}:  For a single example, if $y$ is a one-hot encoded vector representing the true target class (or token) and $\hat{y}$ is the vector of predicted probabilities from the model, the cross-entropy loss can be generally expressed as $L_{CE}(y, \hat{y}) = - \sum_i y_i \log(\hat{y}_i)$. This penalizes the model heavily when it confidently makes an incorrect prediction.
    \item \textbf{F1-score} \cite{lipton2014thresholding}: It is frequently used for classification and structured output tasks where both precision and recall are important. It is the harmonic mean of precision (P) and recall (R): $F_1 = 2 \times \frac{P \times R}{P + R}$. Precision measures the proportion of positive identifications that were actually correct, $P = \frac{\text{True Positives (TP)}}{\text{TP} + \text{False Positives (FP)}}$, while recall measures the proportion of actual positives that were correctly identified, $R = \frac{\text{TP}}{\text{TP} + \text{False Negatives (FN)}}$.
    \item \textbf{BLEU (Bilingual Evaluation Understudy) score} is commonly used in machine translation and other sequence generation tasks to measure the similarity between a candidate translation (model output) and one or more reference translations (gold standard) \cite{papineni2002bleu}. It calculates a score based on the precision of n-grams (contiguous sequences of n items, typically words) common to both the candidate and reference(s), with a penalty for overly short candidate sequences.
\end{itemize}

\subsubsection{Model}
The model refers to the specific mathematical or computational structure that is learned from the data.

\subsubsection{Hyperparameters}
Hyperparameters are configuration settings that are not learned directly from the data but are set prior to the commencement of the learning process. Examples include the learning rate in an optimization algorithm or the number of layers in a neural network. The process of finding the optimal set of hyperparameters for a given problem and dataset.


\subsubsection{Generalization, Overfitting, and Underfitting}
A primary goal of machine learning is generalization: the ability of a model to perform well on previously unseen data, after having been trained on a finite dataset.
Two related common problems are:
\begin{itemize}
    \item \textbf{Overfitting:} This occurs when a model learns the training data too well, capturing noise and specific idiosyncrasies of the training set rather than the underlying patterns. An overfit model performs well on training data but poorly on unseen data. It is often said that the model has "memorized" the training data.
    \item \textbf{Underfitting:} This occurs when a model is too simple to capture the underlying structure of the data. An underfit model performs poorly on both the training data and unseen data. This might indicate that the model needs further training, a more complex architecture, or that the features used are not sufficiently informative.
\end{itemize}
In this work, generalization is assessed by the models' proficiency in generating correct SPARQL queries for previously unseen natural language questions.

One technique used to avoid overfitting in this work is early stopping, which monitores performance on a validation set and halts training when this performance begins to degrade.
Approaches in the field for training models can usually be categorized into supervised learning, unsupervised learning, semi-supervised learning, and reinforcement learning. 
Supervised learning is the method used in this work, and its core principle involves using labeled data (i.e., data where each example is paired with a correct output or target) in the training process to continuously minimize the errors. 

One of the most common and powerful types of models in machine learning is the neural network. Because of their potential for a high number of variables, they offer great flexibility for complex tasks. This characteristic also means they usually require greater volumes of data for effective training compared to some classical machine learning algorithms, such as Decision Trees, which branches data depending on feature values. 
The models explored in this thesis are instances of large-scale \textbf{neural networks}, and the methodologies employed are rooted in the field of Deep Learning.

\subsection{Deep Learning}
Note that this section is based on the lecture materials of \textit{6.036 Introduction to Machine Learning} course by MIT \cite{MITx6.036}

As explained in \textit{Deep Learning} \cite{goodfellow2016deep}, modern deep learning is defined as a class of machine learning algorithms that construct complex architectures by composing simpler structures. However, most contemporary interpretations focus on neural networks \cite{goodfellow2016deep}.
     
    Neural networks, because of their aforementioned properties, are suitable for learning patterns from complex high-dimensional data. Before starting with them, some machine learning concepts need to be defined more formally in the context of deep learning:

    \textbf{Data point}

    As mentioned, data points (examples) x are typically represented as vectors. For neural network operations, we can consider these as column vectors, a data point x with D features will ${\mathbb{R} ^ {D, 1}}$.

    \textbf{Loss Function}

A loss function measures the discrepancy between the predicted output and the true label. Formally, a loss function for one data point is defined as:

\begin{equation}
    \mathcal{L}: \mathbb{R}^{D, 1} \times \mathbb{R}^{D, 1} \rightarrow \mathbb{R}
\end{equation}

where \( D \) is the dimension of the data and the labels.

As introduced in the last section, the cross-entropy loss is a prevalent choice for classification tasks and sequence generation, and often used as a loss function within deep learning models.
    
    \textbf{Parameters or weights}
    
    They are learned from data by the learning algorithm and are the main characters in making predictions after training.
    The parameters $\theta$ of a neural network layer or model are often high-dimensional vectors or matrices. 
    For instance, the weights for a layer processing D-dimensional input might be conceptualized as part of a parameter vector $\theta \in \mathbb{R}^M$ (where M can be very large, encompassing all learnable weights and biases).

    \textbf{Gradient Descent}

    An optimization algorithm, in which the gradient of the loss function is used to update the parameters to minimize the loss (output of the loss function). It can be pictured as going in the opposite direction of the gradient (the steepest descent). More formally, having  $\nabla_\theta \mathcal{L}$, the update of the parameters can be thought of as 
    \begin{equation}
        \theta \coloneq \theta - \eta \nabla_\theta \mathcal{L}
    \end{equation}
    with \(\eta\) being a hyperparameter of the learning algorithm called the learning rate, which determines how big the update of $\theta$ will be.

The neuron is the processing unit in the architecture. One of the earliest models of such a unit is the perceptron, introduced by Frank Rosenblatt \cite{rosenblatt1958perceptron}, which performs a weighted sum of inputs. It is a linear classifier for binary classification that computes the sum:

\begin{equation}
z = \sum w_i x_i + b
\end{equation}

where \( w_i \) are the weights, \( x_i \) are the inputs, and \( b \) is the bias term, which prevents the decision boundary from being constrained to pass through the origin. The output is then determined by the function:

\begin{equation}
f(z) =
\begin{cases} 
1, & \text{if } z \geq 0 \\
0, & \text{if } z < 0
\end{cases}
\end{equation}


Neurons are arranged in layers. Each layer uses the previous layer's outputs for its calculations and then forwards its outputs to the next layer.  For a given layer \( l \), the computation follows:

\begin{equation}
    z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}
\end{equation}

\begin{equation}
    a^{(l)} = \sigma(z^{(l)})
\end{equation}

where \( W^{(l)} \) is the weight matrix, \( a^{(l-1)} \) represents the outputs (activations) from the previous layer, \( b^{(l)} \) is the bias vector, and \( \sigma(\cdot) \) is the activation function. 

There are typically three kinds of layers:

\textbf{Input Layer}

The input layer is a symbolic name since it refers to the input data points, with each node in the layer usually representing a feature of the data points. There is just one input layer.

\textbf{Hidden Layer} 

This is where the bulk of operations take place. They usually compose the majority of the layers.

\textbf{Output Layer}

Aggregates the inputs of the last hidden layer making sense of the data to get an output, which should be interpretable as a result of the specific task (regression, classification).


For complex tasks usually many hidden layers are required in neural networks, which define and give the name to the field of deep learning.

\textbf{Training}

The following explanation refers specifically to the Feed Forward Neural Network architecture as a reference for brevity, although the process with slight modifications is also applied with the next neural networks architectures presented.

There are typically two stages in a training loop: forward pass and backpropagation.

\textbf{Forward Pass}

The forward pass is the process where input data propagates through the neural network layer by layer until it reaches the output. Each neuron in a layer takes inputs from the previous layer, applies weights and biases, and then passes the result through an activation function.  

In training, this step generates predictions based on the current model parameters. The key steps are:  
\begin{itemize}
    \item The input layer receives raw data (e.g., images, text, or numerical values).  
    \item The data is transformed as it moves through hidden layers, where each layer extracts increasingly abstract features.  
    \item The final layer produces an output, which could be a probability distribution (for classification) or a numerical value (for regression).  
\end{itemize}  

After the forward pass, the model's predicted output is compared to the true label or value using a loss function, which quantifies the error. The computed loss serves as feedback for weight updates through backpropagation.  

\bigskip  

\textbf{Backpropagation}

Training a neural network requires adjusting its weights to minimize a loss function. This is achieved through gradient descent, which updates weights based on the gradient of the loss function. The gradient can be computed using batch gradient descent, which sums gradients over all data points, or stochastic gradient descent (SGD), which updates weights with a subset of the data.

For a given training example, consisting of an input $x$ and its corresponding true label $y$, the model produces a prediction $NN(x;W)$. We compute the gradient of the loss function, which measures the discrepancy between this prediction and the true label $y$, with respect to the weights $W$: $\nabla_{W}Loss(NN(x;W),y)$, where \( W \) includes all weight matrices \( W^l \) in layers \( l = 1, \dots, L \). Using the chain rule, the gradient for the final layer \( L \) is:

\begin{equation}
\frac{\partial \text{Loss}}{\partial W^L} = \frac{\partial \text{Loss}}{\partial A^L} \cdot \frac{\partial A^L}{\partial Z^L} \cdot \frac{\partial Z^L}{\partial W^L}.
\end{equation}

Since \( Z^L = W^L A^{L-1} \), it follows that:

\begin{equation}
\frac{\partial Z^L}{\partial W^L} = A^{L-1}.
\end{equation}

Rewriting we have:

\begin{equation}
\frac{\partial \text{Loss}}{\partial W^L} =
\frac{\partial \text{Loss}}{\partial A^L}
\cdot
 \frac{\partial A^L}{\partial Z^L} 
\cdot
A^{L-1}.
\end{equation}

For an arbitrary layer \( l \), we use the recursive property:

\begin{equation}
\frac{\partial \text{Loss}}{\partial W^l} =
A^{l-1} \cdot \frac{\partial \text{Loss}}{\partial Z^l}.
\end{equation}

To compute \( \frac{\partial \text{Loss}}{\partial Z^l} \), we first note that from the forward propagation equation:

\begin{equation}
Z^{l+1} = W^{l+1} A^l + b^{l+1},
\end{equation}

differentiating both sides with respect to \( A^l \) gives:

\begin{equation}
\frac{\partial Z^{l+1}}{\partial A^l} = W^{l+1}.
\end{equation}

So, from:
\begin{equation}
    \frac{\partial \text{Loss}}{\partial Z^l} =
    \frac{\partial A^l}{\partial Z^l} \cdot \frac{\partial Z^{l+1}}{\partial A^l} \cdot \frac{\partial \text{Loss}}{\partial Z^{l+1}}.
\end{equation}

we get:

\begin{equation}
\frac{\partial \text{Loss}}{\partial Z^l} =
\frac{\partial A^l}{\partial Z^l} \cdot W^{l+1} \cdot \frac{\partial \text{Loss}}{\partial Z^{l+1}}.
\end{equation}


Expanding this equation all the way down to the first layer:

\begin{equation}
\frac{\partial \text{Loss}}{\partial Z^1} =
\frac{\partial \text{Loss}}{\partial A^L}
\cdot
\frac{\partial A^L}{\partial Z^L}
\cdot
\frac{\partial Z^L}{\partial A^{L-1}}
\cdot
\frac{\partial A^{L-1}}{\partial Z^{L-1}}
\cdots
\frac{\partial A^2}{\partial Z^2}
\cdot
\frac{\partial Z^2}{\partial A^1}
\cdot
\frac{\partial A^1}{\partial Z^1}.
\end{equation}

And for an arbitrary layer l we have:

\begin{equation}
\frac{\partial \text{Loss}}{\partial Z^l} =
\frac{\partial A^l}{\partial Z^l}
\cdot
W^{l+1}
\cdot
\frac{\partial A^{l+1}}{\partial Z^{l+1}}
\cdots
\cdot
\frac{\partial A^{L-1}}{\partial Z^{L-1}}
\cdot
W^L
\cdot
\frac{\partial A^L}{\partial Z^L}
\cdot
\frac{\partial \text{Loss}}{\partial A^L}.
\end{equation}

\textbf{Vanishing and Exploding Gradients}  

As backpropagation propagates gradients from the output layer to the input layer, the repeated multiplication of weight matrices can lead to two major issues:  

\begin{itemize}
    \item \textbf{Vanishing Gradients:} When the gradient values become exponentially small as they are backpropagated through layers, the earlier layers receive almost no meaningful updates. This slows learning in deep networks.
    \item \textbf{Exploding Gradients:} If the weight updates become excessively large, gradients can grow exponentially, causing disproportionately big updates and oscillations instead of convergence.
\end{itemize}

One of the most common techniques to tackle these problems is dynamically adjusting the learning rate based on the layer and iteration \cite[Chapter 8]{MITx6.036}, a strategy commonly implemented in the widely used Adam optimizer \cite{kingma2014adam}.

\subsubsection{Recurrent Neural Network (RNN)}

\begin{definition}  
    Recurrent neural networks are a family of neural networks for processing sequential data.
\end{definition}  
    
    Unlike FNNs, which process inputs independently, RNNs introduce loops within the network to allow information persistence. This structure enables them to model temporal dependencies, making them suitable for tasks such as time-series forecasting, speech recognition, and in general tasks depending on previous states such as machine translation.
    RNNs are in its core state machines of FNNs, as seen in Figure \ref{fig:RNN}.


    \begin{figure}
        \centering
        \includegraphics{recurrent_neural_network.png}
        \caption{Recurrent Neural Network Architecture \cite[Chapter 12]{MITx6.036}}
        \label{fig:RNN}
    \end{figure} 
    
    A simple RNN consists of an input layer, a recurrent hidden layer, and an output layer. The key difference from FNNs is that the hidden layer maintains a state across time steps. At each time step \( t \), the hidden state \( s_t \) is updated based on the previous hidden state \( s_{t-1} \) and the current input \( x_t \):  
    
    \begin{equation}  
    s_t = f(W_h s_{t-1} + W_x x_t + b_h)  
    \end{equation}
    
    where:  
    \begin{itemize}
        \item \( W_h \) is the weight matrix for the hidden state,  
        \item \( W_x \) is the weight matrix for the input,  
        \item \( b_h \) is the bias term,
        \item \( f \) is an activation function.  
    \end{itemize}
    
    The output \( y_t \) is computed as:  
    
    \begin{equation}
    y_t = W_y s_t + b_y
    \end{equation}
    
    This recurrence allows RNNs to retain context from earlier inputs. 
    
    \bigskip
    
    Just as FNNs, RNNs face challenge of vanishing and exploding gradients. However, this problem is often even more pronounced in RNNs due to their additional temporal dependencies, where the same weights are shared across time steps, and thus not entirely addressable by methods such as the aforementioned adative step size \cite{MITx6.036}.

    To address this further, gated mechanisms were introduced, allowing the model to selectively update or forget certain parts of the hidden state. These gating mechanisms improved the performance of RNNs, especially for handling longer sequences. One such notable architecture is the Long Short-Term Memory (LSTM) network \cite[Chapter 8]{MITx6.036}, which is one of the precursors of current contemporary language models \cite{vaswani2017attention}.

    Next, we will explore the concept of a simple gated recurrent neural network.
    \bigskip

    \subsubsection{Simple Gated Recurrent Neural Network}
    This section is based on Chapter 8 of the notes from the MIT course \textit{Introduction to Machine Learning} \cite[Chapter 12]{MITx6.036}, unless stated otherwise.
    
    In simple gated recurrent networks, we want to control which parts of the last state we keep and in what proportion. Therefore, a new term, the gating value, is introduced, along with a new way of calculating the states. At each time step \( t \), the gating value \( g_t \) is computed as:
    
    \begin{equation}
    g_t = \sigma(W_{gx} x_t + W_{gs} s_{t-1}),
    \end{equation}
    \footnote{It could also have an offset, but this is omitted for conciseness.}
    
    where:
    \begin{itemize}
        \item \( g_t \) is an \( m \times 1 \) vector,
        \item \( W_{gx} \) is an \( m \times l \) weight matrix for the input \( x_t \),
        \item \( W_{gs} \) is an \( m \times m \) weight matrix for the previous state \( s_{t-1} \),
        \item \( \sigma \) denotes the sigmoid activation function, which squashes the values between 0 and 1. It is defined as:
        \begin{equation}
            \sigma(z) = \frac{1}{1 + e^{-z}},
        \end{equation}
        where
        \begin{equation}
            z = W_{gx} x_t + W_{gs} s_{t-1}.
        \end{equation}
    \end{itemize}
    
    This gating mechanism regulates how much and which components of the state \( s_{t-1} \) should be carried over from the previous time step and how much should be updated based on the current input. The new state \( s_t \) is computed as follows:
    
    \begin{equation}
        s_t = (1 - g_t) \cdot s_{t-1} + g_t \cdot f_1(W_{sx} x_t + W_{ss} s_{t-1} + W_{ss}^0),
    \end{equation}

    Adding a new way for the network to regulate ``forgetting'' and ``remembering'' makes the network work better against vanishing and exploding gradients.
    
    \subsubsection{Long Short-Term Memory}
   

The core idea is that LSTMs introduce a dedicated memory cell, essentially another state vector, along with three gating mechanisms. This new state vector preserves long term dependencies.

\begin{itemize}
    \item The \textbf{input gate} determines which components of the memory cell are updated with new values.
    \item The \textbf{forget gate} decides which components of the memory cell should decay towards zero.
    \item The \textbf{output gate} controls which parts of the memory cell contribute to the network’s output.
\end{itemize}

Like simple gated recurrent networks, these gating mechanisms perform weighted selection, allowing the network to regulate information flow effectively. LSTMs have been widely used in tasks such as language translation and speech recognition, being the state-of-the-art solution for handling long-range dependencies in 2015.

\subsection{Large Language Models}
\textit{This section is based on the book Designing Large Language Model Applications by Suhas Pai \cite{pai2025designing} unless stated otherwise.}

Building upon the general definition of a model, in the field of NLP, they usually involve machine translation, text classification, and text completion. 

\begin{definition}
    Large Language Models (LLMs) are deep learning models pre-trained on vast amounts of text data \cite{AWS_LLM}. 
\end{definition}
These models leverage these datasets to capture linguistic structures, cultural references, and nuances. Through their specific architecture and contextual embeddings, they recognize complex relationships between words, enabling a deeper understanding of syntax and semantic.

There is no universally accepted definition of what qualifies a language model as ``large''. The threshold for this classification has evolved over time as models have increased in size. Models that were previously considered large, such as GPT-2 with its 1.5 billion parameters, are now considered small \cite{vannguyen2024surveysmalllanguagemodels}. In his book, \textit{Designing Large Language Model Applications}, Suhai Pai defines ``large'' as having over a billion parameters. However, in this work, a language model is considered large starting from the size of the first BERT model (110 million parameters), as it was the first general-purpose language model that could be fine-tuned for various NLP tasks without architectural changes, representing a turning point in the field of NLP \cite{devlin2019bert}. This characteristic, along with their vast knowledge base derived from massive training corpora, is what makes them the state-of-the-art solution in NLP.

The term ``vast amounts of data'' used to describe the size of training corpora is also vague. Typically, these models are trained on datasets containing hundreds of millions to billions of words. For example, BERT was trained on the BooksCorpus (800 million words) and English Wikipedia (2.5 billion words) \cite{devlin2019bert}, while the Common Crawl dataset, used for training GPT-3 and the LLAMA family of models, contains nearly a trillion words \cite{brown2020languagemodelsfewshotlearners,touvron2023llamaopenefficientfoundation}.

The current most used architecture is called the transformer architecture and it aims to tackle the lack of parallelization possible in the previous models, such as RNNS and LSTMs, sequential in essence \cite{vaswani2017attention}. It reduces training time significantly, in a task like translation between languages, from several days \cite{bahdanau2014neural} to as little as twelve hours.

\subsubsection{Embeddings}

Since the operations involved in training and prediction of neural networks are only defined with numerical data, a two-way representation between natural language and tensors of numbers is needed. One type of such numerical representation is called embeddings.

\begin{definition}
    Embeddings are vector representations of natural language usually learned by deep learning models, that encode semantic knowledge about words and concepts \cite{goodfellow2016deep}.
\end{definition}

A token is a discrete unit of text, such as a word, a sub-word or even a character.

The first step to process input text is breaking it up into tokens, which in modern approaches are usually sub-words, averaging about 4 characters in length in the English language in the SOTA model family of GPT are about 4 characters \cite{OpenAITokens}.

These tokens are then usually mapped to IDs through the vocabulary, which is a look-up table mapping text tokens to numeric IDs.

Finally, additional contextual information is embedded into the IDS during training of most modern models in NLP. They are updated based on surrounding tokens and relative position. For example the token "how" could have different embeddings in the sentences "How are you?" and "That is how you do it".


\subsection{Transformer Architecture}
This section is entirely based on the paper \textit{Attention is All You Need} by Vaswani et al. \cite{vaswani2017attention} unless stated otherwise.

\begin{figure}
    \centering
    \includegraphics{transformer_architecture.png}
    \caption{Transformer Architecture \cite{vaswani2017attention}}
    \label{fig:transformer}
\end{figure}
The Transformer architecture consists of two main components: the encoder and the decoder. The overall structure is illustrated in Figure \ref{fig:transformer}.

\textbf{Encoder}:
The encoder is composed of 6 identical layers. Each encoder layer consists of two sublayers:  

\begin{itemize}
    \item \textbf{Multi-Head Self-Attention}: This mechanism allows each token in the input sequence to attend to all other tokens, enabling global context awareness.  
    \item \textbf{Feed-Forward Neural Network (FFN)}: A position-wise fully connected network applied independently to each token.  
\end{itemize}

Each sublayer has a residual (skip) connection followed by layer normalization. This residual connection helps mitigate the vanishing gradient problem by preserving gradient flow during backpropagation.

\textbf{Decoder}:
The decoder also consists of 6 layers, each containing three sublayers:  

\begin{itemize}
    \item \textbf{Masked Multi-Head Self-Attention}: Unlike the encoder, self-attention in the decoder is masked to ensure that the prediction for a given position can only depend on previously generated tokens. This prevents information from future tokens from leaking.  
    \item \textbf{Multi-Head Cross-Attention}: This sublayer processes the encoder’s output along with the decoders output of the first masked attention sublayer, allowing the decoder to leverage the full context of the input sequence.  
    \item \textbf{Feed-Forward Neural Network (FFN)}: Similar to the encoder, a position-wise feed-forward network is applied.  
\end{itemize}

Each sublayer in both the encoder and the decoder is followed by an add-and-normalize operation, which means adding the output of the residual connection (input of the sublayer) with the ouput of the FNN or the attention mechanism to then normalize it across the features.

After the final decoder layer, a linear transformation projects the output into the vocabulary space. A softmax function then converts this output into a probability distribution over possible next tokens.

Unlike recurrent neural networks (RNNs), which process input sequentially, Transformers process all input tokens in parallel. To preserve positional information, positional encodings are added to the input embeddings before passing them through the encoder.

The main new breakthrough coming with the transformer architecture is the ability to process tokens in parallel while also keeping the dependencies of the ones far apart in the text input and leveraging this information. This provides both a significant speed up in training as well as an increase in performance in certain tasks such as machine translation from English to German \cite{vaswani2017attention}.

\subsection{Mistral Architecture}
\textit{This section is based on the paper ``Mistral 7B'' by Jiang et al. \cite{jiang2023mistral7b} unless stated otherwise.}

The Mistral 7B model is a 7.3-billion-parameter language model that builds upon the foundational Transformer architecture \cite{vaswani2017attention} but introduces several key modifications to enhance efficiency and performance, particularly for long sequence handling and faster inference. 
While it retains the core decoder-only transformer blocks, it incorporates novel attention mechanisms. 
The primary architectural innovations in Mistral 7B are Grouped-Query Attention (GQA) and Sliding Window Attention (SWA).

\textbf{Grouped-Query Attention (GQA)}:
In the standard Multi-Head Attention (MHA) mechanism described by Vaswani et al. \cite{vaswani2017attention}, each attention head has its own query (Q), key (K), and value (V) projections. 
GQA modifies this by having multiple query heads share a single key and value head. 
This approach significantly reduces the number of parameters and computational overhead associated with projecting and storing keys and values, especially during autoregressive decoding where the K and V tensors (KV cache) from previous tokens are cached and reused. 
By grouping query heads, GQA aims to strike a balance between the quality of MHA and the speed of Multi-Query Attention (MQA), where all query heads share a single K and V head \cite{shazeer2019fast}. This design leads to faster inference times and reduced memory usage compared to traditional MHA, without a substantial loss in model quality.

\textbf{Sliding Window Attention (SWA)}:
To handle longer sequences more efficiently and mitigate the quadratic complexity of full self-attention with respect to sequence length, Mistral 7B employs Sliding Window Attention. In SWA, each token does not attend to all other tokens in the sequence. Instead, attention for each token is restricted to a fixed-size window of preceding tokens. For example, with a sliding window of size $W$, a token at position $i$ can attend to tokens in the range $[i-W, i]$. This significantly reduces computation since each token only processes a subset of the sequence.

Despite the limited attention span at each layer, information can propagate beyond the window size $W$ through the stacking of multiple transformer layers. A token at layer $k$ can indirectly incorporate information from tokens beyond $W$ steps away at layer $k-1$ due to the receptive field expanding with network depth. For instance, after $L$ layers, the effective attention span can be much larger than $W \times L$. Mistral 7B uses a sliding window size of 4096 tokens. This mechanism, combined with optimizations like FlashAttention \cite{dao2022flashattention} and xFormers, allows for efficient processing of longer sequences and a linear computational cost with respect to sequence length, $O(W \cdot \text{seq\_len})$.

Furthermore, SWA enables a more memory-efficient KV cache management. With a fixed attention span, the cache size can be limited to $W$ tokens using a rotating buffer (also referred to as a rolling buffer cache). As new tokens are processed, older KV pairs beyond the window size are evicted from the cache. This can lead to significant memory savings during inference for long sequences without a notable degradation in model performance for tasks that do not strictly require attention over extremely long dependencies at every layer.

These architectural choices allow Mistral 7B to outperform larger models on various benchmarks while being more computationally efficient for inference and requiring less memory.
\subsection{Transfer Learning}
\begin{definition}
    Transfer learning refer to the situation where what has been
learned in one setting (i.e., distribution P1) is exploited to improve generalization
in another setting (say distribution P2) \cite{goodfellow2016deep}.
\end{definition}

In simple terms, it involves leveraging training from one task to improve a machine learning model’s performance on another task.

A special kind of transfer learning, called cross-lingual transfer, revolves around leveraging training in one language to improve the results of training in another language \cite{cross_lingual_transfer}.

In 2018, the introduction of BERT and GPT-1 demonstrated that it was possible to train a general-purpose LLM for various downstream tasks with minimal architectural modifications \cite{devlin2019bert,lee2018pre}. Since then, transformer-based LLMs have been gaining in popularity and in performance because of the flexibility and relatively small set of data required to effectively train for the downstream tasks.

Different methods have been developed to cater to small datasets and low hardware resources, by lowering the tunable parameters and the model's precision \cite{parthasarathy2024ultimate}.

\subsection{Continual Pre-training of Large Language Models}
Refers to the addition of new data as knowledge base to an already trained large language model without merging the old dataset and the new one to start the training from scratch \cite{gupta2023continual}.

A key aspect of this process is selecting an appropriate learning rate that minimizes loss on new data while preserving performance on the original data. This is vital since further training on new data, which may follow a different distribution than the original dataset, can introduce a distribution shift. This shift can lead to a decrease in performance on previously learned data. Research indicates that the right parameters might make continual pre-training better performing than training from scratch on the whole data \cite{gupta2023continual}.
