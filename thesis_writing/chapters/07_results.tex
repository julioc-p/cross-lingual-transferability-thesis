\section{Results}\label{section::results}

This section presents the empirical findings obtained from the experimental setup detailed previously. 
The focus herein is on the objective presentation of the performance metrics and observed outcomes for the fine-tuned models. 
An interpretation of these results and their broader implications will be provided in the next Section~\ref{section::discussion}.

\subsection{Baseline Performance}\label{sec:baseline_results}

To establish a performance benchmark prior to fine-tuning, the instruction-tuned versions of the base models, specifically \url{mistralai/Mistral-7B-Instruct-v0.1} and \url{occiglot/occiglot-7b-eu5-instruct}, were evaluated.
These evaluations were conducted on the relevant test sets using prompting strategies consistent with both the v1 (without explicit entity/relationship ID mappings) and v2 (with explicit entity/relationship ID mappings provided as context) experimental conditions. 
This approach allows for an assessment of the models' inherent capabilities under different input scenarios before the fine-tuning interventions. 
For these baseline evaluations, the "English" or "German" designation refers to the language of the input queries from the respective test sets, not to different underlying base models. 
The key metrics reported include Macro F1-Score (F1), Macro Precision (P), Macro Recall (R), and the percentage of Executable Queries (Exec.). 
Full evaluation summaries for the baseline models are provided in Appendix~\ref{appendixbaselinedetailedresults}.

\subsubsection{Baselines v1}\label{sec:baseline_v1_context}

For the v1 context, the instruction-tuned models were prompted with the natural language question and the target knowledge graph, without any additional entity or relationship ID mappings.

\paragraph{QALD-10 Test Set (v1 Context)} \mbox{}\\
Performance on the QALD-10 benchmark (391 questions attempted after filtering) was as follows:
\begin{itemize}
    \item \textbf{Mistral 7B Instruct v0.1 (English queries):} F1: 0.0026, P: 0.0512, R: 0.0026, Exec: 5.12\%. One query (0.26\%) was correct (both empty).
    \item \textbf{Mistral 7B Instruct v0.1 (German queries):} F1: 0.0000, P: 0.0384, R: 0.0000, Exec: 4.09\%. No correct answers.
    \item \textbf{Occiglot-7b-eu5-instruct (English queries):} F1: 0.0026, P: 0.1125, R: 0.0026, Exec: 12.53\%. One query (0.26\%) was correct (both empty).
    \item \textbf{Occiglot-7b-eu5-instruct (German queries):} F1: 0.0000, P: 0.0793, R: 0.0000, Exec: 8.44\%. No correct answers.
\end{itemize}
Under this v1 prompting style, the base models demonstrated extremely limited capability on QALD-10, with F1-scores near zero and high rates of query execution failures (87-96\%).

\paragraph{v1 Test Set} \mbox{}\\
On the custom v1 test set (3,500 examples per language):
\begin{itemize}
    \item \textbf{Mistral 7B Instruct v0.1 (English queries):} F1: 0.0223, P: 0.2411, R: 0.0223, Exec: 24.26\%. Correctness (Exact Match + Both Empty) was 2.23\% (all "Correct (Both Empty)").
    \item \textbf{Mistral 7B Instruct v0.1 (German queries):} F1: 0.0123, P: 0.1600, R: 0.0124, Exec: 16.26\%. Correctness was 1.23\% (all "Correct (Both Empty)").
    \item \textbf{Occiglot-7b-eu5-instruct (English queries):} F1: 0.0160, P: 0.1989, R: 0.0160, Exec: 21.60\%. Correctness was 1.60\% (all "Correct (Both Empty)").
    \item \textbf{Occiglot-7b-eu5-instruct (German queries):} F1: 0.0146, P: 0.1977, R: 0.0146, Exec: 20.89\%. Correctness was 1.46\% (all "Correct (Both Empty)").
\end{itemize}
Performance on the v1 test sets also remained very low, with high query execution failure rates (76-84\%).

\subsubsection{Baselines v2 (Instruction-Tuned Models with Explicit ID Mappings)}\label{sec:baseline_v2_context}

\paragraph{QALD-10 Test Set (v2 Context)} \mbox{}\\
\begin{itemize}
    \item \textbf{Mistral 7B Instruct v0.1 (English queries):} F1: 0.0138, P: 0.2202, R: 0.0157, Exec: 23.79\%. Correctness (Exact Match + Both Empty) was 1.28\% (1.28\% Exact Match, 0\% Both Empty).
    \item \textbf{Mistral 7B Instruct v0.1 (German queries):} F1: 0.0130, P: 0.2226, R: 0.0179, Exec: 24.55\%. Correctness was 1.28\% (0.77\% Exact Match, 0.51\% Both Empty).
    \item \textbf{Occiglot-7b-eu5-instruct (English queries):} F1: 0.0217, P: 0.2540, R: 0.0230, Exec: 28.90\%. Correctness was 2.05\% (1.79\% Exact Match, 0.26\% Both Empty).
    \item \textbf{Occiglot-7b-eu5-instruct (German queries):} F1: 0.0053, P: 0.1510, R: 0.0077, Exec: 18.67\%. Correctness was 0.51\% (0.51\% Exact Match, 0\% Both Empty).
\end{itemize}
Providing contextual ID mappings in the v2 prompt style led to a modest increase in the percentage of executable queries on QALD-10 for some configurations compared to the v1 context, but overall F1-scores remained very low (below 0.022), with query execution failure rates still high (71-81\%).

\paragraph{v2 Test Set} \mbox{}\\
On the v2 test set (10,000 examples per language) with v2 prompting including context:
\begin{itemize}
    \item \textbf{Mistral 7B Instruct v0.1 (English queries):} F1: 0.0457, P: 0.3891, R: 0.0476, Exec: 42.93\%. Correctness (Exact Match + Both Empty) was 4.45\% (0.88\% Exact Match, 3.57\% Both Empty).
    \item \textbf{Mistral 7B Instruct v0.1 (German queries):} F1: 0.0422, P: 0.3685, R: 0.0436, Exec: 40.54\%. Correctness was 4.17\% (0.75\% Exact Match, 3.42\% Both Empty).
    \item \textbf{Occiglot-7b-eu5-instruct (English queries):} F1: 0.0210, P: 0.2043, R: 0.0217, Exec: 22.32\%. Correctness was 2.08\% (0.21\% Exact Match, 1.87\% Both Empty).
    \item \textbf{Occiglot-7b-eu5-instruct (German queries):} F1: 0.0219, P: 0.1889, R: 0.0223, Exec: 20.90\%. Correctness was 2.19\% (0.13\% Exact Match, 2.06\% Both Empty).
\end{itemize}
While the provision of explicit context in the v2 prompting style improved executability rates for Mistral Instruct on the Custom v2 test set compared to its v1 context performance on the v1 test set (e.g., from 24.26\% to 42.93\% for English), the Macro F1-Scores remained very low (below 0.046). 
Query execution failures were still prevalent (57-80\%).

Across all baseline conditions, the pre-trained instruction-tuned models, even when provided with contextual entity/relationship mappings, demonstrated limited inherent capability for the complex text-to-SPARQL generation task. 
These initial low performance levels underscore the necessity of task-specific fine-tuning.


\subsection{Performance of Fine-tuned Models}

This section outlines the performance of the v1 and v2 finetuned models. As explained in \ref{section::experimental_setup}, the v1 models are finetuned on the base of instruction tuned models while the v2 on raw base models or non instruction tuned ones.
When a language is mentioned in this section it refers to both the language of the queries used as well as the Language used to finetune the model.
It is important to remember that the v1 models did not have the entity/relationship mapping neither in the finetuning nor in the generation, while the v2 models had them in both.
